# Night Channel

An atmospheric web application delivering curated ambient audio streams with a retro aesthetic.

## Documentation
- [Technical Specification](docs/SPEC.md)

## Features
- Immersive retro aesthetic and UI styling.
- Continuous ambient audio streaming with custom controls.
- Serverless backend integration for metadata and stream routing.

## Tech Stack
- **Frontend:** React, Vite, CSS3
- **Backend:** Node.js / Vercel Serverless Functions (`api/`)
- **Testing:** Vitest (`tests/`)

## Getting Started
```bash
npm install
npm run dev
```
